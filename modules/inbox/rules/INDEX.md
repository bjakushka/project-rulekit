## Inbox: raw ideas

- `inbox.md` holds rough thoughts, kept so they are not forgotten. Log them
  there as they come up
- One thought per `#` heading. Keep the context under it short, about three
  lines, but write more when the thought needs it. An entry is raw because it
  has not been developed into a task yet, not because it is short
- A thought here is unprocessed: worth remembering, not yet decided on
- Do not track status or priority here
- Do not polish this file too much
- Remove an entry once it has been dealt with

Entry format:

```markdown
# Example entry

A rough thought, usually two or three lines. Enough to recognise it later,
not a worked-out plan.
```
