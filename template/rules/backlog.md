## Backlog: concrete tasks, ready to be picked up

- `backlog.md` holds actionable tasks, concrete enough to start from without
  asking what was meant. Log them there as they come up
- One task per `#` heading, description under it
- Every task carries a `Status:` line, one of: `ready`, `needs a plan`,
  `in progress`
- A task too large to start from a description gets a plan in
  `plans/<task-name>.md`, linked under its description
- Remove a task when it is done

Task format:

```markdown
# Example task

Status: ready

What needs doing and why, in a couple of sentences. Concrete enough to start
from without asking what was meant.
```
